Access

Admin tools sit behind a single access check, and every admin page requires an administrator account. Users can only see their own transfers, wallets and cash-outs.

Ledger activity

  • Each payment is recorded before it is submitted, so a transfer is never sent twice.
  • A payment whose outcome is unclear is never retried automatically; it is checked against the ledger first.
  • Balances change only after the ledger confirms a transaction.

Reporting a problem

If you think you've found a security issue, email security@example.com with:

  • the page or feature affected,
  • the steps to reproduce it, and
  • what you expected to happen and what happened instead.

We'll acknowledge your report within two working days and keep you updated while we look into it. Please give us a reasonable chance to fix the issue before sharing it publicly.

Testing guidelines

  • Only test against accounts you created yourself.
  • Don't try to access, change or delete other people's data.
  • Don't run tests that would slow the platform down for others.

As a student project we can't offer rewards, but we're grateful for every report and happy to credit you if you'd like.
